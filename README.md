# Sistema de Biblioteca

Fiz esse programa em Python pra controlar os livros da biblioteca de uma escola.

## O que ele faz

- cadastrar livro
- ver os livros e se estao disponiveis ou com algum aluno
- emprestar livro pra um aluno
- registrar quando o aluno devolve
- salva tudo num arquivo (livros.json) pra nao perder

## Como usar

```
python biblioteca.py
```

## O que aprendi

Usei funcoes, listas, dicionarios, menu com while e try/except pra tratar erro de digitacao. Tambem aprendi a salvar e ler arquivo JSON.
